危险操作

将删除所有学员、班次、例外与出勤记录，且不可恢复（导入备份可还原）。

一、日常用法

  1. 排课：到「班次管理」按 星期+时段 添加班次（如 周日上午1班）。日历自动铺到对应星期；调整排期用「编辑」，停开用「停用」（历史出勤保留，且停用后默认从列表隐藏）。误添加的班次可用「删除」彻底移除（含其出勤）；停用的班次可在列表上方「显示已停用的班次」找回并重新启用。
  2. 例外日期：班次行点「例外」可设置某天停课或加课/补课。停课会隐藏该日此班并清除其出勤；加课在某非固定日额外排一节课。调课 = 原日停课 + 新日加课。
  3. 加学员：到「学员管理」输入姓名，勾选所属班次（可多选）。中途退课/转班用「编辑」改所属班次或标记为「已退出」（停用后默认从列表隐藏，可在「显示已停用的学员」找回）；误添加可用「删除」彻底移除。
  4. 登记出勤：在「课程日历」点具体班次标签 → 勾选到勤 → 保存。可用「全选到勤 / 全体缺勤」。改动后未保存会提示。
  5. 查个人出勤：到「个人查询」选学员（切换学员即刷新），日历高亮出勤日期并分行列出当天各班次；可用「单月/双月」切换，双月用于跨收费周期对照；底部显示应到/实到/出勤率。
  6. 班次总览：到「班次总览」选班次，按月查看每位学员的应到、实到与出勤率。

二、数据保全（重要）

  • 所有数据存在本机。请定期「导出备份」到下载目录/网盘。
  • 系统自动只保留最近 36 个月左右的出勤与例外数据：每月第一次打开应用时清理一次，更早的会被删除（实际保留 36～37 个月）；如需长期留存请导出备份。
  • 换手机或重装 App 后，用「导入备份」恢复。

三、打包成安卓 App（PakePlus）

  1. 打开 PakePlus，选择「打包本地文件 / 本地 HTML」。
  2. 选中本 index.html 所在文件夹（即本应用根目录）。
  3. 填写应用名称、选一个图标，目标平台选 Android，开始打包，得到 APK。
  4. 手机允许「安装未知来源应用」后安装即可使用。

提示：本应用是纯静态网页，无需联网、无需服务器。任何支持「网页转 App」的工具都能打包，不限于 PakePlus。
